LOGEN — OFFLINE CHROME APP

Open LogEn.html with Google Chrome. Refresh the tab after an update.
No launcher, server, installation, account or internet is required.

Download the eight-column template or use LogEn_Shift_Inventory_Template.xlsx.
Part Number | QTY in Box | QTY boxes per Pallet | Consumption per shift
DOH (Days on hand) | L(mm) | W(mm) | H(mm)

Required pallets = ROUNDUP(ROUNDUP(consumption per shift / QTY in Box /
QTY boxes per Pallet x selected shifts per day, 0) x DOH, 0).
Multiply by 1, 2 or 3 selected shifts BEFORE rounding the daily demand.
Then multiply by DOH. Raw consumption calculations keep their decimals.

Check Stackability under Shifts & days on hand to edit a factor for each part.
Unchecked uses one-high floor storage and keeps the saved factors.
Height limits still apply. Rack calculations do not use floor stacking.

Dimensions are loaded pallet dimensions. Floor stacking defaults to one high.
Ground-depth limit 0 means unrestricted; floor m² uses actual occupied depth.
Click a part number for formulas. Export results creates five Excel sheets.

Projects → Delete project asks for confirmation.
Deleted projects → Restore project recovers inventory and settings.
Projects → Download backup before moving the file or clearing browser data.
